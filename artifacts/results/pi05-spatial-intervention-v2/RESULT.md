## Sequential gate

The locked gate was **positive**: targeted achieved 40/40 and random achieved 37/40. Paired outcomes were 3 wins, 0 losses, and 37 ties (two-sided sign-test p=0.250).

Original-distribution data was released for the fair comparison. Oracle was cancelled before start at zero SU because Targeted reached the 40/40 ceiling; dose-24 oracle evidence already exists, so dose-8 oracle would not answer a necessary remaining gate question.

## Decision

Targeted data changed target success versus no intervention by +48%, with lift versus matched random of +7% and versus original-distribution data of +80%.

The preregistered targeted-selection hypothesis is supported at this dose by the locked point-estimate rule. A larger dose is required only if requested by the decision engine.

On paired plans, targeted versus random had 3 wins and 0 losses (two-sided sign-test p=0.250); this paired test quantifies uncertainty around the locked point-estimate decision.

Decision engine: Targeted data is the highest-value tested intervention within the regression limit.
